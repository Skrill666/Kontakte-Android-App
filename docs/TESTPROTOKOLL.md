# Testprotokoll

## Automatisierte Tests

```bash
npm run test
npm run build
npm run verify
```

## Nativer Abnahmetest

- [ ] Berechtigungen werden erklärt und angefordert.
- [ ] Ablehnung führt nicht zum Absturz.
- [ ] Mindestens 20 vorhandene Kontakte werden angezeigt.
- [ ] Sortierung nach Vorname ist aufsteigend.
- [ ] Suche nach Vor- und Nachname funktioniert.
- [ ] Jeder Listeneintrag zeigt Foto oder Platzhalter.
- [ ] Detailseite zeigt Vorname, Nachname, Telefon, E-Mail und Geburtstag.
- [ ] Zurückbutton funktioniert.
- [ ] Jede Telefonnummer kann geöffnet und kopiert werden.
- [ ] Jede E-Mail-Adresse kann geöffnet und kopiert werden.
- [ ] SMS-App öffnet mit vorausgefüllter Nummer.
- [ ] Kontakt wird nach Bestätigung systemweit gelöscht.
- [ ] Neuer Kontakt wird systemweit gespeichert.
- [ ] Daten bleiben nach Neustart bestehen.
- [ ] Android-Zurückgeste schützt ungespeicherte Eingaben.
